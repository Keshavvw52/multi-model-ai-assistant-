# Multi-Modal AI Assistant 

A full-stack AI application that can understand and interact with **text, images, videos, audio, and documents** using LLMs.

---

##  Tech Stack

### Frontend
- Next.js (App Router)
- TypeScript
- Tailwind CSS

### Backend
- Node.js + Express
- Groq API (LLM + Whisper)

### Features
-  Chat with AI
-  Upload media (image, video, audio, document)
-  AI-based media analysis
-  Streaming responses (real-time)
-  Conversation history
-  Export conversations
